### Exercici 7
Crea un mapa del terreny d’un joc amb una matriu 10x10. Després omple el mapa amb els següents caràcters de manera aleatòria:
- terra: 0
- tresor: 💎
Mostra un menú amb les següents opcions
1. Vull excavar! 
2. Sortir
El programa ofereix al jugador l’opció de fer excavacions i provar sort. Té 3 intents per excavar i al final dels intents ha de mostrar la quantitat de diamants (💎) que ha trobat.
